# NotesSmasher

NotesSmasher is an AI-assisted student notes sharing platform developed using Flask.

## Features

* User authentication system
* Upload and manage study notes
* AI-assisted explanation feature
* Responsive user interface
* Database integration using SQLite
* Google OAuth login support

## Tech Stack

* Python
* Flask
* HTML
* CSS
* SQLite

## Deployment

The project is deployed online using Render.
